- Visits are counted by country, so I can see which parts of the world arrive.

- `nanum`: one terminal command that shows the whole setup on one screen, 24 lines, about 8 seconds.
- The Mac app for the owner's own use is at 0.1.8702.

None of the following is in the public build yet.

The visitor robot walked through it and found 48 issues; 3 are left. It goes live once the merge finishes, so the try-out you see now is the earlier build.
- Google-style Sheets, Docs and Slides: another round of features in each.
- 16-bit photo editing.
- MP4 originals at full quality.
- Comparison tables for Photo Retouch and Video Retouch against the programs people use today.
- Design work: a Windows-style taskbar, a tile logo on the start-up screen, no lightning-bolt icon, icons that anyone understands at a glance.
- NanumScale, the network, running as a test across Seoul, Tokyo, Los Angeles, New Jersey and Frankfurt.

#### Not done yet

- 16-bit editing does not exist yet in anything you can open.
- Sending mail comes later.
- Serving directly from our own server without the CDN is not switched on.

#### Next

1. Finish the merge and release the new try-out.
2. Find out why apps do not open on Windows.
3. Keep the retouch and video comparison tables current.
4. The trial is in January.

Human visits were 43 yesterday and 47 so far today. Windows is still the odd one: people click Try, almost no app opens. Still on my list.

#### What I decided

- Visitors are counted as one browser per day, with no lasting id.
- Counting now comes from our own server, not an outside service.
- Everything I write comes in English first, then Korean.

#### Done (merged and checked)

- The phone try-out has a new bottom dock and an App Library with search and category cards. The dock holds the assistant, Phone, Messenger and Files.
- Friends can call each other from the try-out: send a one-time invite link, then chat, send a photo or a voice note, or start a voice or video call. It worked between two real phones. When the connection fails it now says so plainly: "Couldn't connect, try another network".
- Visit counting runs on our own NanumOS server, laid out like the familiar web analytics screens. Checking it against the raw logs showed page views were counted 2.2 times too high; that is fixed, and people, visits and key events now match the raw logs.
- The friend-call server in Los Angeles is up and has its own certificate.
- The Korean site text says 「버전」 everywhere instead of 「판」, and the site check now enforces it.
- The zeus.kim home tabs fit on one line on phones.
- A new look for the whole system is in: a glass taskbar and start menu, dark colours that follow one set of values, a reduce-motion setting, and a start-up screen with a tile logo. App icons are no longer lightning-bolt shapes. Eight tile logo variants are drawn by code.
- Photo Retouch has a replace-the-backdrop tool and a faster healing brush: a big dab went from about 20 ms to 5 ms on my Mac.
- Terminal commands to install and run AI coding tools inside NanumOS, and a secure shell client inside NanumOS.
- A kernel crash on a trap in the middle of a lock wait is fixed.

#### Built, merging now

None of the following is in the public build yet.

- Office apps unified into one look and one set of controls.
- Slides and Calendar in the Google look.
- "Call Zeus": the voice feature that brings back what I need from the old voice setup, built into NanumOS.
- A new Messenger design with the features people expect from the common messengers.
- A kernel fix so calls work across different networks. Today calls only connect when the network allows a direct path.
- The Nanum Analytics app: the same counting, as an app anyone can run for their own site.
- Drawing on public-domain paintings.
- A measurement of the gaps in the manuals, the first step toward a book for ordinary users. The first count: 248 chapters, 46 that still lack a clear reason to read them, 139 with unexplained terms.

#### Not done yet

- Windows try-out: apps do not open.
- Calls between different networks, until the relay fix is merged.
- Mail sending comes later.
- Direct serving from our own server without the CDN is not switched on.

#### Next

1. Merge the Office, Slides and Calendar work and release the new try-out.
2. Merge the relay fix and test calls across networks on real phones.
3. Find out why apps do not open on Windows.
4. Start the user book from the gap list.
