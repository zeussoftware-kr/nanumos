# NanumOS

*A clean new computer, inside the one you already have.*

NanumOS is a small operating system that runs as a window on the computer you already use, and on a phone. It comes with its own apps: documents, sheets, slides, mail, calendar, photo and video editing, a browser, a terminal, and an assistant you can talk to.

This repository is the public progress record. It shows what is done, what is being built and what is planned. It does not contain the source code.

- **Try it now, nothing to install:** https://nanumos.com/try
- **Website:** https://nanumos.com
- **Feature map:** https://nanumos.com/map
