# Contributing

This repository holds the public progress record of NanumOS: daily logs, the feature list and the release list. It has no source code, so there is nothing to send a pull request against.

**Pull requests are not accepted.** Issues are welcome:

- **Bug**: something in the try-out (https://nanumos.com/try) or the Mac app did not work. Use the "Bug" form.
- **Idea**: something you would like NanumOS to do. Use the "Idea" form.

Please do not put passwords, keys or personal files in an issue. A screenshot of the try-out is fine.

## 참여

이 저장소에는 소스 코드가 없어 풀 리퀘스트는 받지 않습니다. 흠 신고와 바라는 점은 Issues 에 남겨 주세요. 비밀번호·열쇠·개인 파일은 적지 마세요.
